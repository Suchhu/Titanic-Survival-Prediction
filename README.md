# Titanic Survival Prediction

## Overview

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

## Dataset

Titanic Dataset from Kaggle

## Technologies

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-Learn
- Streamlit

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest

## Best Accuracy

85%

## Features

- Passenger Class
- Gender
- Age
- Fare
- SibSp
- Parch

## Deployment

Streamlit Cloud
